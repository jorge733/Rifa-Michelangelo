# Rifa 2° Medio 2026 · Colegio Waldorf Michelangelo

Página web de la rifa (HTML, CSS y JavaScript), publicada con Vercel.

```
index.html       Estructura de la página
css/styles.css   Estilos (mobile-first)
js/app.js        Lógica: grilla de números, selección y total
assets/images/   Imágenes (logo, premios)
```

Precio y cantidad de números: constantes `PRECIO` y `TOTAL_NUMEROS` al inicio de `js/app.js`.
